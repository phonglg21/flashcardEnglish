# TOEIC Flashcards

Web ôn từ vựng TOEIC: thẻ lật, lặp lại ngắt quãng (Leitner), trắc nghiệm kiểu Part 5, bộ từ theo chủ đề.

## Lưu ý

- Dữ liệu học lưu trong trình duyệt của từng thiết bị. Dùng nút **Sao lưu / Khôi phục** ở tab Thêm từ để chuyển giữa điện thoại và máy tính.
- Trắc nghiệm tự tạo câu hỏi từ câu ví dụ của từng từ, nên câu ví dụ cần chứa đúng từ đó.
