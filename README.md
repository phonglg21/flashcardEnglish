# TOEIC Flashcards

Web ôn từ vựng TOEIC: thẻ lật, lặp lại ngắt quãng (Leitner), trắc nghiệm kiểu Part 5, bộ từ theo chủ đề. Chỉ gồm một file `index.html`, không cần cài đặt.

## Đưa lên GitHub Pages

1. Tạo repository mới trên GitHub, ví dụ `toeic-flashcards`.
2. Upload `index.html` (và `README.md`) vào nhánh `main`.
3. Vào **Settings → Pages**, ở mục **Branch** chọn `main` và thư mục `/ (root)`, rồi bấm **Save**.
4. Sau khoảng 1-2 phút, web chạy tại `https://<tên-github>.github.io/toeic-flashcards/`.

## Lưu ý

- Dữ liệu học lưu trong trình duyệt của từng thiết bị. Dùng nút **Sao lưu / Khôi phục** ở tab Thêm từ để chuyển giữa điện thoại và máy tính.
- Trắc nghiệm tự tạo câu hỏi từ câu ví dụ của từng từ, nên câu ví dụ cần chứa đúng từ đó.
